# AI-College-Counselor-for-Personalized-Career-Course-Advice
# Overview
An AI College Counselor is a system that advises students on career paths, course selection, internships, and skill development, tailored to each student’s profile, goals, performance, and preferences.
# Features 
Internship/job match,
Career mapping,
New student onboarding,
Skill gap remediation
